# Waive

Waive помогает найти товары в каталоге Softline по названию, артикулу или описанию задачи. Модель E5-small участвует в смысловом поиске и распознавании опечаток. Для закупок доступны сравнение предложений, подбор совместимых дополнений и подготовка запроса коммерческого предложения.

[Публичный стенд](https://softlinehackaton.cloudru-edu.ru/) · [Закупки для бизнеса](https://softlinehackaton.cloudru-edu.ru/business) · [Описание решения и результаты проверки](docs/submission.md)

## Локальный запуск

1. Скопируйте `.env.example` в `.env` и задайте пароль. В `DATABASE_URL` используйте тот же пароль, кодируя специальные символы по правилам URL.
2. Запустите PostgreSQL, примените миграцию и загрузите каталог:

```sh
docker compose up -d db
docker compose run --rm api alembic upgrade head
docker compose run --rm api python -m app.import_catalog /catalog/Mindbox.xml.gz
docker compose up -d api
```

3. Откройте <http://localhost:8000>. Проверка готовности -- `GET /ready`. Поиск -- `GET /search?q=...`.

Импорт принимает обычный XML и gzip. Он строит снимок и индекс в одной транзакции. При ошибке активный снимок остаётся доступным. Повторная загрузка того же содержимого не создаёт копию. Локальная конфигурация Compose использует одну роль БД.

## Итоговая выдача и допродажи

`results` содержит прямые совпадения, `recommendations` -- допродажи. Веб-интерфейс показывает первые 12 найденных семейств и открывает следующие по кнопке «Показать ещё». Параметр API `expanded=true` возвращает все ранжированные семейства среди кандидатов запроса. Без этого параметра `results` по-прежнему содержит до четырёх совпадений. Поле `top4` всегда ограничено четырьмя семействами и используется для оценки. При точном совпадении артикула сохраняется выбранный SKU, а среди остальных вариантов приоритет у доступных предложений с ненулевой ценой. Для товаров без семейства совпадающие поставщик и нормализованное название считаются одним семейством.

При импорте нового снимка поиск строит карту связей по всем заполненным категориям. Правила учитывают назначение дополнения и проверяют применимые поля отдельных товаров. Для ПО это поддерживаемая ОС и лицензионные условия, для оборудования — разъём, интерфейс, формат или явно указанная совместимая модель. Поиск и закупки используют единый подбор по выбранной карточке. В ответе указываются характеристики, по которым подтверждена связь. При недостатке данных показывается статус, объясняющий отсутствие подтверждённого комплекта.

Если подходящие прямые предложения недоступны, доступные аналоги показываются отдельно. При подборе учитываются категория назначения, требования запроса и сравнимые параметры исходной позиции, если она известна. Непрозрачный отсутствующий артикул получает сообщение об отсутствии совпадения. Поле `top4` использует проверенные результаты, аналоги и дополнения и содержит до четырёх семейств.

Поисковая фраза может задавать платформу и её версию, редакцию, тип и срок лицензии, бюджет, наличие, число рабочих мест или пользователей и исключения вроде «без подписки». Каждое требование проверяется на одном предложении. Неуказанное количество и минимальный заказ не подтверждают охват лицензии.

## Подсказки и сравнение

После ввода двух символов поиск предлагает до шести вариантов из доступных предложений. Поиск и автодополнение используют общие варианты названий брендов, например «майкр» для Microsoft. Для этих брендов распознаются и набранные в другой раскладке варианты. Подсказки проверяют точные артикулы и ID, а при отсутствии подходящего семейства с четырёх символов используют названия отдельных товаров. Подсказку можно выбрать мышью или стрелками и Enter. Escape закрывает список.

При опечатке поиск и подсказки используют общий список кандидатов из каталога и словаря брендов. Близкие варианты сравниваются с учётом пропусков, перестановок, клавиатурных соседей и раскладки. Поиск сохраняет введённые версии и артикулы. Если несколько вариантов близки, их можно выбрать в блоке «Возможно, вы имели в виду».

При пустом запросе доступен весь каталог с постраничной загрузкой. Ценовая сортировка оставляет предложения без цены в конце. Популярность учитывает переходы в карточку за 30 дней и исключает демо-сеансы. При равном числе переходов сохраняется исходный порядок. Релевантность при пустом запросе показывает сначала предложения в наличии.

Многоязычная E5-small строит векторы для смыслового поиска и оценивает варианты исправления опечаток. Например, для «адинэсс» модель предлагает AnyDesk. Подсказки и поиск проверяют вариант на одном снимке каталога. Близкие совпадения система исправляет автоматически, когда правила подтверждают выбор модели. Вариант, найденный только моделью, можно выбрать в подсказках или после Enter. Артикулы, версии и остальной текст запроса сохраняются. При недоступности E5 работают правила исправления. Русское «впн» ищет по тому же термину, что и VPN. При вводе бренда кириллицей Waive подбирает производителей из активного каталога и передаёт их на проверку E5. Для «кактус картридж» поиск сохраняет слово «картридж» и ограничивает выдачу производителем Cactus.

Кнопка «В сравнение» добавляет карточку в список из четырёх предложений. Таблицу можно открыть после выбора двух. Выбор сохраняется при переходе к другому запросу. В таблице выделяются отличия цены, наличия и условий лицензии. Если характеристики нет в фиде, отображается «Нет данных в каталоге».

## Подключение смыслового поиска

Для смыслового поиска используем E5-small. Загрузка занимает около 0,49 ГБ без контейнера и зависимостей. Том `waive-model-cache` хранит веса отдельно, контейнер читает их без сети. Укажите известную ревизию:

```sh
export MODEL_REVISION=fd1525a9fd15316a2d503bf26ab031a61d056e98
docker volume create waive-model-cache
docker run --rm -e MODEL_REVISION -v waive-model-cache:/models \
  -v "$PWD/inference/download.py:/download.py:ro" python:3.12-slim python /download.py
docker compose -f compose.yaml -f compose.semantic.yaml up -d --build inference api
docker compose -f compose.yaml -f compose.semantic.yaml run --rm api python -m app.index_semantic
```

Перед индексацией дождитесь запуска inference. Проверить режим можно через `GET /search?q=...&semantic=true` и поле `search_mode`. Режим `semantic=false` подходит для сравнения. Точные артикулы обрабатываются текстовым поиском. При отсутствии готового индекса или таймауте модели API также использует текстовый поиск. Новый снимок сразу доступен для текстового поиска. Смысловой режим включается для него после полной индексации. Каталог ранжируется по расстоянию между векторами через pgvector.

## Развёртывание

Публичный стенд работает на одной ВМ. API, PostgreSQL и E5-small запущены в Docker Compose. HTTPS принимает Nginx.

Для самостоятельного развёртывания репозиторий содержит конфигурацию с Caddy. На Linux VPS укажите DNS-имя в `WAIVE_HOST`, откройте TCP 80 и 443 и направьте DNS на сервер. Примените миграции, импортируйте XML и подготовьте том модели по шагам выше. Поднимите все три файла Compose:

```sh
docker compose -f compose.yaml -f compose.semantic.yaml -f compose.production.yaml up -d --build
```

В этой конфигурации HTTPS принимает Caddy. PostgreSQL и сервис модели доступны по внутренней сети Compose.

## Оценка и стоимость

Скрипт `scripts/evaluate.py` проверяет попадание целевого семейства или категории на первую позицию и в топ-4. Запуск после прогрева и полной индексации:

```sh
docker compose exec -T api python - < scripts/evaluate.py
```

При запуске с дополнительными файлами Compose передайте их и здесь. Отчёт показывает результаты отдельно для десяти эталонов и пяти смысловых формулировок. Метрики на уровне семейства и категории не заменяют ручную проверку версии и лицензии у каждой карточки.

E5-small работает на той же ВМ, что API и PostgreSQL. Цена вызовов внешнего API модели составляет 0 ₽. Инфраструктурная стоимость одного поиска рассчитывается делением месячных затрат на 15 000 запросов при расчётной нагрузке 500 запросов в день.

Для проверки задержки своего стенда используйте:

```sh
python3 scripts/measure.py --mode lexical --requests 1000 --rps 10
python3 scripts/measure.py --mode hybrid --requests 1000 --rps 10
```

Скрипт показывает p50, p95 и p99, фактический RPS, ошибки и частоту перехода в текстовый режим. Параметр `--url` задаёт адрес тестируемого стенда. Оценка на публичном стенде описана в [материалах проекта](docs/submission.md), расширенная выборка описана в [методике сравнения](docs/benchmark.md).

### Условия закупки

Панель «Фильтры» постоянно видна под строкой поиска. Разделы «Категория» и «Условия лицензии» раскрываются отдельно. Можно выбрать платформу, срок и тип лицензии, наличие и диапазон цены в рублях. Ценовой фильтр учитывает обе границы включительно и пропускает предложения с известной рублёвой ценой. Подсказки извлекают условия лицензии из текста запроса, их применение подтверждает покупатель. Для каждого семейства все выбранные условия проверяются на одном предложении по снимку каталога. В диагностике учитываются найденные поиском семейства. Если ослабление одного фильтра вернёт варианты, интерфейс показывает их число и число семейств без подтверждения этой характеристики.

### Подбор для компании

Откройте «Закупки для бизнеса» под строкой поиска или перейдите на `/business`. Платформу, срок и тип лицензии можно выбрать в фильтрах. Число рабочих мест указывается в списке на согласование и учитывается при подборе комплекта и формировании запроса КП.

Предложения из разных поисков можно добавить в список на согласование. Кнопка «Подобрать комплект» в закупках или «Подобрать дополнения» в обычном поиске появляется у доступных позиций с применимым правилом. Waive проверяет характеристики дополнения на той же версии каталога. Кнопка «Запросить КП» открывает форму с обязательными полями имени, почты, телефона и компании. Список на согласование хранится в браузере. На публичном стенде доступен черновик КП и открытие письма в почтовом приложении.

Для автоматической отправки заполните `QUOTE_RECIPIENT`, `SMTP_HOST`, `SMTP_PORT` и `SMTP_FROM` в серверном `.env`. Если почтовый сервис требует вход, задайте также `SMTP_USERNAME` и `SMTP_PASSWORD`, затем пересоздайте API. Порт 465 использует SMTP через TLS, остальные порты используют STARTTLS. При отсутствии настроек Waive открывает письмо в почтовом приложении пользователя. TXT и CSV доступны из списка на согласование.
