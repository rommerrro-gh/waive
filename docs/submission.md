# Waive · Материалы первого этапа

## Черновик описания для формы

Waive помогает пользователю Softline найти решение по названию, артикулу или описанию задачи. PostgreSQL находит текстовые совпадения. E5-small превращает запрос в вектор, а pgvector подбирает семейства со схожим назначением. По двум выдачам ранжируются конкретные предложения. Учитываются версия, доступность и артикул. Близкие варианты и сопутствующие товары выводятся отдельно. При отказе модели сервис продолжает работать через текстовый поиск.

Стек -- Python, FastAPI, PostgreSQL 16, pgvector, pg_trgm, PyTorch CPU, sentence-transformers, HTML/CSS/JavaScript, Docker Compose и Caddy. В каталоге организаторов 136 040 предложений. Оценочная выборка состоит из десяти эталонных запросов и отдельных смысловых формулировок. Для запуска используйте README в репозитории.

Наработки -- открытая модель intfloat/multilingual-e5-small и её токенизатор, библиотеки и образы из README, исходный каталог и эталоны Softline. Команда реализовала импорт, индекс, объединение результатов, API, интерфейс, правила рекомендаций и инструменты проверки.

Перед сдачей добавьте фактические ссылки, версию кода, итоговые метрики с размером выборки, ограничения качества и стоимость по шаблону. Отдельно укажите, если стенд работает на одной VM и тест отказа БД в продакшене не проводился.

## Видео одним дублем

- 0:00–0:20. Открыть стенд, кратко объяснить задачу покупателя.
- 0:20–1:00. Ввести длинный запрос, который по оценке лучше обрабатывается моделью. Сравнить обычный и гибридный режим на той же формулировке.
- 1:00–1:40. Показать найденную версию КриптоПро CSP 5.0 и условия конкретной лицензии. Не обещать, что проверены все типы лицензий.
- 1:40–2:15. Ввести Office для дома и бизнеса. Показать, почему близкие варианты отдельно, и открыть сопутствующую рекомендацию.
- 2:15–2:45. Назвать проверенное сравнение, состав расходов на один запрос и одно ограничение. Записать видео одним непрерывным фрагментом и проверить звук.

## Стоимость запроса

Единица -- один завершённый запрос в поиске с показом рекомендаций. Базовая нагрузка из брифа -- 15 000 запросов за 30 дней. При одном VPS разделить его месячный тариф плюс отдельно оплачиваемые хранение и резервные копии на 15 000. Расходы на внешний модельный API -- 0 ₽. Не добавлять стоимость локального CPU поверх тарифа того же VPS. Указать тариф, дату, валюту, параметры сервера и источник.

Для сравнения затрат гибридного и текстового режимов запустить один профиль дважды после прогрева. Записать p95, долю ошибок, успешный RPS и долю выдач в режиме `hybrid`. Если часть запросов перешла в текстовый режим, не интерпретировать весь прогон как нагрузку E5 на каждый запрос. Стоимость первой индексации и последующих обновлений учесть по правилам официального шаблона. Среднюю стоимость до выбора тарифа не указывать.

## Проверка перед отправкой

- Открыть URL стенда и репозитория без входа в аккаунт.
- Проверить четыре карточки или подписанные альтернативы на выбранных запросах.
- Подтвердить с организаторами распространение исходного фида и порядок оценки альтернатив.
- Сверить выводы в форме с отчётом оценки того же коммита.
- Загрузить форму, видео, ссылку на публичный репозиторий с историей, URL стенда и расчёт по официальному шаблону.

## Замеры для черновика

Прогон GitHub Actions № 45791736548 на коммите `36d41c1` загрузил полный каталог и построил 12 538 векторных документов за 6 минут 34 секунды. Тест после остановки E5 подтвердил, что API вернул текстовую выдачу. На пяти последовательных проверочных запросах медиана составила 105,2 мс в текстовом режиме и 130,0 мс в гибридном. Это замеры CI на малой выборке. Для оценки нагрузки используйте отдельный прогон.

Проверенный сценарий для видео -- «восстановить файлы после сбоя». Текстовый поиск на этой формулировке не вернул карточек, гибридный нашёл варианты O&O MediaRecovery. Перед записью повторить запрос на актуальном коммите. Запрос про доступ к рабочему компьютеру из дома можно показать отдельно как пример подбора категории. После добавления правил категории оба режима уже выдают подходящий товар на первой позиции, поэтому этот пример не показывает вклад E5.
