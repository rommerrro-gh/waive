# Waive для каталога Softline

[Открыть стенд](https://softlinehackaton.cloudru-edu.ru/) · [Закупки для бизнеса](https://softlinehackaton.cloudru-edu.ru/business) · [Исходный код и история](https://github.com/rommerrro-gh/waive)

## Краткое описание решения

Waive помогает покупателю найти решение в каталоге Softline по названию, артикулу или описанию задачи. Поиск распознаёт кириллические написания иностранных названий и опечатки. Покупатель может сузить выдачу фильтрами, сравнить до четырёх предложений и подобрать дополнения с пояснением совместимости. В разделе закупок выбранные позиции можно добавить на согласование и сформировать запрос коммерческого предложения.

## Как работает поиск

PostgreSQL и pg_trgm находят совпадения по артикулу, названию и данным каталога. Многоязычная E5-small строит эмбеддинги для смыслового поиска через pgvector и оценивает варианты исправления. Подсказки показываются при вводе и после отправки запроса. При ранжировании имена товаров, производители и описания учитываются отдельно. Например, по запросу «диджитал» первой выводится карточка Liqvid Digital Signage. По запросу «восстановить файлы после сбоя» поиск находит программы восстановления данных.

Для допродаж Waive сначала определяет подходящий тип дополнения, затем проверяет свойства конкретной позиции по каталогу. Для программ это может быть поддерживаемая ОС, для оборудования -- интерфейс или явно указанная совместимая модель. Основание подбора отображается в карточке. Если товар недоступен, подтверждённые аналоги выводятся отдельно.

## Возможности прототипа

- Каталог из 136 040 предложений, подсказки, фильтры по категории, наличию, цене и условиям лицензии.
- Сортировка по релевантности, цене и популярности, сравнение до четырёх карточек.
- Подбор дополнений и список закупки на согласование с количеством рабочих мест.
- Форма запроса КП и выгрузка черновика TXT и списка CSV. Публичный стенд открывает черновик письма в почтовом приложении.

## Данные и технологии

Использованы каталог и эталонные запросы Softline, открытая модель intfloat/multilingual-e5-small и её токенизатор. Команда реализовала импорт и версионирование каталога, поиск, подсказки, ранжирование предложений, подбор дополнений, веб-интерфейс и оценку качества.

Стек: Python, FastAPI, PostgreSQL 16, pgvector, pg_trgm, sentence-transformers и PyTorch на CPU, HTML/CSS/JavaScript, Docker Compose и Nginx. Публичный стенд работает на одной ВМ. Модель загружена на сервер и обслуживается локально.

## Проверка качества

28 ноября 2026 года на публичном стенде с приложением 058f935 проверены 10 эталонов Softline и 5 запросов с описанием пользовательской задачи. В каждой группе проверялось попадание целевого семейства или категории.

| Набор | Первое место | Топ-4 |
| --- | ---: | ---: |
| Эталоны Softline | 9 из 10 | 10 из 10 |
| Запросы с описанием задачи | 5 из 5 | 5 из 5 |

Это контрольная выборка. Она подтверждает попадание цели и не оценивает релевантность каждой карточки. Методика для расширенной выборки описана в [отдельном документе](benchmark.md). Проверки запускаются через [GitHub Actions](https://github.com/rommerrro-gh/waive/actions).

## Границы прототипа

Подбор совместимости опирается на данные активного снимка каталога. Материалы с сайтов производителей не проверяются при каждом запросе. Для точного артикула или строгих условий выдача может содержать меньше четырёх товаров, если подтверждённых совпадений недостаточно. Автоматическая почтовая отправка на публичном стенде отключена.
